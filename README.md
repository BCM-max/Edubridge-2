# Java OOP Programs

## Overview
This repository contains three Java programs demonstrating fundamental Object-Oriented Programming (OOP) concepts.

## Programs

### 1. Student Details
**File:** `StudentDetails.java`

- Creates a `Student` class.
- Stores USN, Name, Branch and Phone number.
- Creates N Student objects using an array of objects.
- Displays student details with suitable headings.

**Concepts:** Classes, Objects and Arrays of Objects.

### 2. Shape – Inheritance and Polymorphism
**File:** `ShapeDemo.java`

- Creates a parent class `Shape`.
- Creates three subclasses: `Circle`, `Triangle` and `Square`.
- Implements `draw()` and `erase()` methods in each subclass.
- Demonstrates runtime polymorphism through method overriding.

**Concepts:** Inheritance, Method Overriding and Runtime Polymorphism.

### 3. Resizable Interface
**File:** `ResizableDemo.java`

- Creates an interface named `Resizable`.
- Declares `resizeWidth(int width)` and `resizeHeight(int height)` methods.
- Implements the interface in the `Rectangle` class.
- Demonstrates resizing of rectangle dimensions.

**Concepts:** Interfaces and Implementation.

## How to Run

Navigate to the project folder:

```bash
cd Java_OOP_Programs
```

**Program 1**
```bash
javac StudentDetails.java
java StudentDetails
```

**Program 2**
```bash
javac ShapeDemo.java
java ShapeDemo
```

**Program 3**
```bash
javac ResizableDemo.java
java ResizableDemo
```
